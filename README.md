# 密码匣 PassVault

> 纯本地 · 零依赖 · 单文件的加密密码管理器 —— 数据永远只留在你自己的设备上。

🔗 **在线使用（HTTPS）**：https://w22w2.github.io/passvault/

密码匣是一个用原生 HTML / CSS / JavaScript 编写的密码管理器。整个应用只有一个 `index.html` 文件，
不需要服务器、不需要后端、不需要联网，也不需要任何第三方库或构建工具。

---

## 为什么是「纯本地」

大多数在线密码管理器即使宣称加密，你的数据仍存放在厂商的服务器上。密码匣的取舍相反：

- **没有服务器** —— 所有数据加密后存储在你浏览器的 IndexedDB 里，不上传、不同步、不联网。
- **没有账号** —— 不需要注册、不需要邮箱，只有一个你自己设定的主密码。
- **没有依赖** —— 不引用任何 CDN、统计脚本或第三方 SDK，源代码完全可审计。

代价是：它不会自动跨设备同步，也无法由厂商帮你重置密码。因此我们提供了**恢复码**与**生物识别**
作为主密码之外的两条找回 / 解锁通路。

---

## 功能特性

- **信封加密架构（DEK / KEK 分离）**
  随机生成一把数据钥匙（DEK）用于加密全部数据；主密码、恢复码、生物识别各自独立地包裹这把 DEK。
  因此**修改主密码、用恢复码找回**时无需重新加密整个数据库，只需重新包裹一次 DEK。
- **强加密**：`AES-256-GCM` 加密，`PBKDF2-SHA256` 派生密钥，迭代次数 `600,000`。
- **主密码**：可随时修改；支持可选的「密码提示」，帮助你在锁屏上回忆线索。
- **恢复码找回**：首次设置时生成一次性恢复码（20 位 Crockford Base32，形如 `XXXXX-XXXXX-XXXXX-XXXXX`）。
  忘记主密码时用恢复码即可重设密码，**数据不丢失**；也可随时在设置中重新生成。
- **生物识别解锁**：基于 `WebAuthn PRF` 扩展调用 iPhone Face ID / Touch ID 快速解锁，主密码作为后备。
- **自定义分类**：除内置分类外，还能自定义密码类型的名称、图标与颜色。
- **密码生成器**：可控制长度与字符集，一键生成强随机密码。
- **TOTP 两步验证**：保存的验证器密钥可直接在条目中查看动态验证码。
- **回收站**：删除的条目先进入回收站，误删可恢复。
- **备忘录导入 / 导出**：支持以文本备忘录形式批量导入与导出。
- **加密备份**：导出时需再次验证主密码，导出内容保持加密。
- **自动锁定**：切换后台立即锁定，可自定义无操作自动锁定时长。
- **多套配色主题** + iOS 风格液态玻璃界面。
- **PWA 桌面入口**：可添加到手机桌面，像原生 App 一样从主屏图标直接打开。

## 快速开始

### 在线使用（推荐，手机可直接运行）

直接访问：

```
https://w22w2.github.io/passvault/
```

首次进入时设置主密码，并**务必抄写保存恢复码**。

### 本地运行

下载 [index.html](./index.html)，在本目录启动一个本地服务器后访问：

```bash
python -m http.server 8000
# 然后打开 http://localhost:8000/index.html
```

> ⚠️ 直接双击以 `file://` 打开时，浏览器会把它当作**不安全上下文**，`Web Crypto` 与 `WebAuthn`
> 会被禁用，应用无法正常加密与运行。请使用上面的 HTTPS 地址（或 `http://localhost`）。

### 添加到手机桌面

在手机浏览器打开上面的 HTTPS 地址后：

- **iOS Safari**：分享 → 添加到主屏幕
- **Android / 鸿蒙**：菜单 → 添加到主屏幕 / 添加到桌面

添加后可从主屏图标直接打开，并支持「新增密码 / 密码生成器 / 搜索」快捷动作。

## 安全说明

- 数据使用 `AES-256-GCM` 加密后存储在本地 IndexedDB，**不进行任何网络传输**。
- 主密码、恢复码、生物识别三把钥匙各自独立包裹数据钥匙，任意一把都能在不重加密全库的前提下单独更换。
- 生物识别依赖 `WebAuthn PRF` 扩展；若设备或浏览器不支持 PRF，应用会**明确停用**该功能，而不会降级为不安全的实现。
- 受 iOS Safari 限制，调用 Face ID 必须先有用户点击手势，因此网页端**无法做到「打开即刻自动弹窗」**；
  应用会在锁屏出现后尽力自动尝试，并保留手动触发按钮。
- 若忘记主密码且同时丢失了恢复码与生物识别凭证，数据将无法恢复 —— 这是纯本地加密的必然代价。
